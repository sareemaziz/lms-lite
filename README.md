# LMS-Lite

A lightweight Library Management System for tracking books, members, and borrowing in a small campus library. Built as a construction-quality exercise, it features fully encapsulated classes with private fields, defensive pre-condition validation, a clean error hierarchy, a clock-injection seam for deterministic testing, and a decomposed service layer, all backed by a comprehensive test suite.

## Install

```bash
npm install
```

## Run the demo

```bash
node src/cli/index.js
```

## Run tests

```bash
npm test
```

## Run tests with coverage

```bash
npm run test:coverage
```

## Lint

```bash
npm run lint
```
